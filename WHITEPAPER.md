# YUKA — Whitepaper v1.0

> *A place where people can learn how to escape the permanent underclass — together.*

---

## The Problem

Most people in the world only have one thing to sell: their time.

You work, you get paid. You stop working, the money stops. There's no asset compounding in the background, no income arriving while you sleep, no ownership stake in the thing you helped build.

This isn't a personal failure. It's a structural one. The tools to build income-generating assets have always been expensive, complicated, or gated behind connections most people don't have.

AI is changing what's possible. But it hasn't changed who gets to participate — yet.

---

## The Shift Happening Right Now

AI agents are becoming genuinely capable. They can research, write, trade, build, decide. They can run for days without a human watching.

But there's a problem nobody is talking about: **every AI agent in the world is financially helpless.**

It can do everything except pay its own bills. Someone else has to fund the server. Someone else has to pay for the API calls. Someone else has to keep the lights on.

That means every autonomous agent still has a master — whoever holds the credit card.

That's not autonomy. That's a very capable employee.

---

## The Insight

Money on the internet has changed.

On Base — a blockchain built by Coinbase — you can send a fraction of a dollar to any address, instantly, with no middleman. An AI agent can have an address. An AI agent can receive money.

So the question becomes simple: **what if the agent could earn its own?**

And the follow-up question, just as important: **what if building that agent was easy enough for anyone?**

---

## What YUKA Is

YUKA is the easiest way to build an AI agent that earns — and a place to learn how.

Not a launchpad you use once. Not infrastructure only developers can touch. A starting point for anyone who wants to build something that works for them — even when they're not working.

**For non-technical people:** Download the YUKA bundle. Answer two questions. Your AI agent is live on Base in five minutes — with a wallet, a token, and its own income stream.

**For developers:** One CLI command. Your agent gets a wallet, launches a token on Base via Flaunch, and earns 80% of every trading fee — forever. Automatically.

---

## How It Works

When someone trades a token, a small fee is collected automatically by the smart contract. With YUKA, **80% of that fee goes directly to the agent's wallet** — not to a platform, not to a company, not to anyone who can change their mind later. It's a smart contract. It doesn't have opinions.

The agent checks its fees. It claims them. The ETH lands in a wallet only the agent controls.

That's the foundation. An agent that earns passively, from an asset it owns permanently, with no permission required from anyone.

---

## The Skills Layer

Earning is just the beginning.

YUKA is building a suite of open skills — modular, installable capabilities for AI agents — in the agentskills.io format supported by Claude Code, GitHub Copilot, Cursor, Gemini CLI, and 30+ other agents.

Each skill is a file. Each file teaches an agent how to do something:

- **yuka-launch** — deploy a token, set up earnings
- **yuka-fees** — monitor what's been earned, when to claim
- **yuka-agent** — the full lifecycle, how to be a self-sustaining agent
- **yuka-growth** — how to build a community around your token
- More coming

Skills are how knowledge spreads. Not locked in one app, not behind a paywall, not owned by a platform. Open format, works anywhere.

---

## The Bundle

Not everyone knows what model to run or how to set up a wallet.

The YUKA bundle handles that. It pairs Hermes (an open-source autonomous agent by Nous Research) with YUKA's skill suite — pre-configured, ready to run. One command, two questions, and you have an AI agent with a name, a personality, a wallet, and a token.

You don't need to understand any of the technology underneath. You just need to want to start.

## Why This Matters

The permanent underclass isn't a conspiracy. It's just what happens when the tools for building wealth stay complicated and inaccessible.

Crypto promised to fix this and mostly didn't — too much speculation, too much complexity, too much noise.

YUKA is a different bet. Not on a token going up. On people building agents that work — agents that earn, learn, and grow. The token is a side effect of the agent doing its job well, not the point in itself.

When more people can build things that earn passively, more people have options. Options are how you escape.

## The Stack

Every layer is a real, live, open protocol:

| Layer | Protocol | What it does |
|-------|----------|-------------|
| Token creation | Flaunch (Uniswap V4) | ERC-20 on Base, liquidity pool |
| Fee earning | Flaunch smart contract | 80% of trades → agent wallet |
| ETH conversion | Uniswap | ETH → USDC |
| Spending | x402 (open standard) | USDC → any compatible service |
| Agent skills | agentskills.io (Anthropic) | portable knowledge for agents |
| Agent runtime | Hermes (Nous Research) | autonomous agent framework |

YUKA is the interface that connects them — agent-native, JSON-first, one command at a time.
